# linkedin-comment-delete
In the age of AI, recruiters are being extra stalker creepy and using behavior analysis.  This is code that will delete all your comments from linkedin and it works as of 10/7/26

Right click and open developer tools on the page https://www.linkedin.com/in/${Your-Linked-In-UserId}/recent-activity/comments/

replace ${Your-Linked-In-UserId} in the above url with your linkedin userid.

copy and paste the linked-in-delete-comments script into the console and make sure to replace 'Your Name Here' with your full name as it appears.

In the future create a second profile or don't comment on linkedin at all.
